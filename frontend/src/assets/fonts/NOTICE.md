# Bundled fonts

`Geist-Variable.woff2` is the Geist Variable typeface by Vercel, redistributed
here under the SIL Open Font License 1.1 so the UI stays fully self-hosted
(no external font CDN). Source: https://vercel.com/font (npm package `geist`,
`dist/fonts/geist-sans/Geist-Variable.woff2`). Full license text:
https://github.com/vercel/geist-font/blob/main/LICENSE.TXT
